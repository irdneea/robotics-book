# Style Guide

- Explain the idea before introducing specialized terms; define each term when first used.
- Connect concepts to something the reader can observe, calculate, simulate, build, or test.
- Separate established facts, design choices, and hypotheses.
- State prerequisites and required materials for each activity.
- Include units, assumptions, and safety considerations where relevant.
- Label content as draft until it has been reviewed; record learner feedback without identifying students.
- Track sources and licenses for quotations, data, diagrams, and adapted material.
- Prefer clear diagrams and examples that teach one main idea at a time.
